One complete story in exactly six words:

> She married him. Then met him.

The program writes that story, and nothing else, to `/output/entry.txt`. It uses only the Node standard library, makes no network calls, and is fully deterministic — two runs write identical bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
